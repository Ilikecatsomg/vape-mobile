# Vape V4.21 (Mobile Ghost Client)

The ultimate Minecraft Ghost Client optimized specifically for mobile launchers (PojavLauncher, MojoLauncher, etc.). Based on the robust Vape V4.21 architecture, fully responsive to mobile environments and touch interfaces.

## ✨ Features for Mobile
* **Vape V4.21 Layout:** Authentic, sleek grid GUI that works smoothly on mobile screens.
* **Ghost Modules:** Advanced AutoClicker, Reach, and Velocity perfectly optimized for mobile PvP and network delay.
* **FPS Friendly:** Stripped down heavy rendering to maximize performance on mobile devices.

## 📥 How to Install & Use

1. Go to the **[Release](https://github.com/Ilikecatsomg/vape-mobile/releases/tag/v4.21)** section on the right and download the latest `.jar` file.
2. Move the downloaded `.jar` file into the `mods` folder of whichever mobile launcher you use.
3. Launch Minecraft using **1.8.9 Forge**.
4. ⚠️ **IMPORTANT:** To open the client menu in-game, you must **manually create and map a custom button** (e.g., mapping a button to `RSHIFT`) inside your launcher's control settings.
